# Heart Disease Prediction

A machine learning project that predicts the presence of heart disease in patients from their clinical attributes, using the UCI Heart Disease dataset.

## Overview

Cardiovascular disease is one of the leading causes of death worldwide, and identifying at-risk patients early can support timely medical intervention. This project frames that task as a binary classification problem: given a patient's clinical measurements, predict whether or not heart disease is present.

## Dataset

- Source: UCI Machine Learning Repository - Heart Disease (https://archive.ics.uci.edu/dataset/45/heart+disease)
- Size: ~303 patient records (Cleveland subset)
- Features: 13 clinical attributes, including age, sex, chest pain type, resting blood pressure, serum cholesterol, fasting blood sugar, resting ECG results, maximum heart rate, and exercise-induced angina
- Target: presence (1) or absence (0) of heart disease

## Objective

Build and evaluate a binary classification model that predicts heart disease, with particular attention to recall and false negatives given the medical context.

## Evaluation

Model performance is assessed using accuracy, precision, recall, F1-score, and ROC-AUC, prioritizing the reduction of false negatives.
